# AutoABM 1.0.0

First public product release of **AutoABM** — an AI-native agent-based modeling (ABM) research workbench.

## Highlights

- Simulation-first desktop workbench (Interface, canvas, Trace, ODD)
- Research and conversation modes for model building and evidence-grounded explanation
- Local Mesa kernel via sidecar for reproducible runs
- Windows x64 installer: `AutoABM-1.0.0-win-x64.exe`

## Download

Install the Windows desktop app from the assets below, then launch AutoABM and start a research session.

## Notes

- This is the first tagged product release (`v1.0.0`).
- macOS / Linux packages are not included in this release.
